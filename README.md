# Orbit CRM prototype

A browser based interface for the 2Clicks client operations workflow.

## Open it

Open `index.html` in a modern browser. No build step is required.

## Demo views

Use the account menu in the top right to switch between Administrator, Team member, and Client views. Create tasks, set client and employee assignment, choose a priority and due date, then use the task row menu to update status or hand a task to another team member. The Activity page shows the task history.

Demo changes are stored in this browser's local storage. Use the browser's site data controls to reset the demo back to its sample tasks.

## Production work still needed

This is a frontend prototype. It does not implement email or mobile number sign-in, password or OTP verification, a shared database, server side access controls, notifications, or deployment. Those require a backend and production identity provider before client and employee accounts can use the system securely across devices.
